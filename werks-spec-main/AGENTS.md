# AGENTS.md

## Mission

Build WERKS as a trustworthy, phone-first AI operating layer for small service businesses.

## Repository protocol

1. Read `MASTER_CONTEXT.md`.
2. Read `manifest.yaml`.
3. Read all approved documents relevant to the task.
4. Make the smallest coherent change.
5. Update documentation when implementation decisions change.
6. Run tests or add them when changing code.
7. Never mark work complete without explicit acceptance criteria.

## Product constraints

- The MVP tests trust in customer interaction and low-risk operational action.
- Human approval is required when permissions or confidence demand it.
- Every external action must have an audit record.
- Prefer integrations and adapters over hard-coded vendor assumptions.
- Measure time saved, revenue recovered, and error rate.
