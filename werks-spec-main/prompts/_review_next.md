# Review the current WERKS draft

Review the first file in `manifest.yaml` whose status is `draft`.

## Review against

- `MASTER_CONTEXT.md`
- Any approved dependency documents
- Product coherence
- Technical feasibility
- MVP discipline
- Security and permission implications
- Measurable acceptance criteria
- Internal contradictions
- Vague or generic statements
- Missing edge cases

## Required actions

1. Edit the draft directly to resolve issues that can be resolved from repository context.
2. Add unresolved matters to `Open Questions`.
3. Add a short `Review Notes` section only if a material trade-off needs recording.
4. Change status to `review` when it is coherent but still needs founder approval.
5. Change status to `approved` only when the document has no material unresolved product decision.
6. Stop after reviewing one file.
